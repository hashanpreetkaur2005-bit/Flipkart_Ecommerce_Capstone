# 🛒 Flipkart E-commerce Decision Intelligence

### Machine Learning and Data Science Capstone Project

## 📌 Project Overview

This project focuses on analyzing Flipkart e-commerce customer data using Python, Data Science, and Machine Learning techniques.

The main objective is to extract meaningful business insights, understand customer purchasing patterns, perform customer segmentation, predict Average Order Value (AOV), and compare machine learning models to support data-driven business decisions.

## 🎯 Project Objectives

1. Analyze and understand e-commerce customer data.
2. Perform data cleaning and exploratory data analysis (EDA).
3. Identify customer purchasing patterns.
4. Perform customer segmentation using K-Means Clustering.
5. Apply Principal Component Analysis (PCA) for dimensionality reduction.
6. Build an Average Order Value (AOV) prediction model.
7. Compare machine learning models based on performance metrics.
8. Generate meaningful business insights.

## 📊 Project Methodology

### 1. Data Collection
Customer data is used for analyzing e-commerce purchasing behaviour.

### 2. Data Cleaning
- Handling missing values
- Data preprocessing
- Feature preparation

### 3. Exploratory Data Analysis (EDA)
- Understanding customer data
- Identifying patterns and trends
- Data visualization

### 4. Customer Segmentation
K-Means Clustering is used to group customers based on their purchasing characteristics.

### 5. Dimensionality Reduction
PCA is applied to reduce data dimensions and support analysis.

### 6. AOV Prediction
A regression model is developed to predict Average Order Value.

### 7. Model Comparison
Machine learning models are compared using:
- Accuracy
- Precision
- Recall
- F1 Score

## 🤖 Machine Learning Models

The project includes comparison of the following models:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- AdaBoost
- Neural Network

K-Means Clustering is also used for customer segmentation.
